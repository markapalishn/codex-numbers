# Codex Numbers

Маленький нативный индикатор macOS: плавающая строка с расходом токенов,
нативное оформление Liquid Glass на macOS 26 и новее, значок ◈ в строке меню и автоматическое обновление каждые две секунды. Подписи на русском языке,
числа плавно меняются за 0,55 секунды. При системной настройке уменьшения
движения анимация отключается.
Работает локально, без API-ключей, сетевых запросов и дополнительных библиотек.

## Использование

`make install` собирает приложение, устанавливает его в `~/Applications`,
сразу запускает и включает запуск при входе через пользовательский LaunchAgent.
Для сборки нужны инструменты командной строки Xcode со Swift.

Строку можно перетащить за фон. Через значок ◈ можно скрыть/показать её,
вернуть на экран и завершить приложение. Положение сохраняется.
После завершения через меню приложение снова запустится при следующем входе.
`make uninstall` удаляет установленное приложение и автозапуск.
`make help` показывает остальные команды.

## Что означают числа

- `отправлено`: сумма входных токенов всех обращений к модели в одном пользовательском
  запросе, включая обращения после вызова инструментов.
- `из кэша`: часть input, прочитанная из кэша. Не прибавляйте её к input.
- `получено`: выходные токены, включая reasoning, если они включены в счётчик Codex.
- `контекст ≈`: оценка заполнения окна по `last_token_usage.total_tokens /
  model_context_window`. Это не сумма токенов запроса и не точная копия
  процента в интерфейсе Codex; внутренние резервы и сжатие могут отличаться.
- `↻`: запрос выполняется; после завершения его итог остаётся на экране.

При одновременной работе нескольких задач отображается задача с самым свежим
событием расхода/завершения. Это не обязательно открытая вкладка Codex.
Сессии, помеченные как subagent, исключаются; расход отдельных дочерних сессий
не добавляется к родительскому запросу.

## Источник и ограничения

Приложение читает события `token_count`, `task_started`, `task_complete` и
`turn_aborted` из `$CODEX_HOME/sessions` (по умолчанию `~/.codex/sessions`).
Формат проверен на локальных журналах Codex 14 сентября 2026 года; это внутренний
формат, который может измениться. Облачные задачи без локального журнала
не отображаются. Текст запросов не сохраняется и никуда не отправляется.

Сумма строится по разнице накопительных счётчиков: повторные события расхода
не задваиваются. Журналы читаются частями; незавершённые строки ожидают дописывания.
При запуске сначала загружаются 12 последних файлов, затем остальные.
Проверки подсчёта, границ запросов, повторов и дописывания файлов: `make test`.
Для диагностики текущих чисел: `make snapshot`.
