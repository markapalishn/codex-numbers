# Установка Codex Numbers

Программа собирается на вашем Mac из исходников. Готовый установщик пока
не публикуется. Установка не требует API-ключа, Homebrew или прав администратора.

## Что потребуется

- Mac с macOS 26 или новее для оформления Liquid Glass.
- Установленный Codex с локальными задачами: программа читает его журналы.
- Актуальные Xcode Command Line Tools с macOS SDK 26 или новее.
  Они предоставляют Swift, Git, Make и Python 3.
- Доступ к репозиторию GitHub, если он ещё приватный.

Программа проверена на Apple Silicon. Сборка создаётся для архитектуры вашего
Mac; работа на Intel отдельно не проверялась.

## 1. Подготовьте инструменты

Откройте приложение «Терминал» через Spotlight и выполните:

```sh
xcode-select --install
```

Подтвердите установку в окне macOS и дождитесь завершения. Если инструменты
уже установлены, переходите дальше. Если установленная версия слишком старая,
обновите Command Line Tools через «Системные настройки → Основные → Обновление ПО».

## 2. Скачайте проект

В Терминале выполните по очереди:

```sh
git clone https://github.com/markapalishn/codex-numbers.git
cd codex-numbers
```

Папка проекта появится в текущей папке Терминала. Сохраните её: через неё
можно обновлять и удалять программу.

Если GitHub сообщает `Repository not found`, проверьте доступ к репозиторию
и авторизацию в GitHub: приватный репозиторий доступен только участникам.

## 3. Установите программу

Из папки проекта выполните:

```sh
make install
```

Команда соберёт приложение, установит его в `~/Applications/Codex Numbers.app`,
сразу запустит и включит автозапуск при входе в macOS.
Пользовательский файл автозапуска:
`~/Library/LaunchAgents/local.codex-numbers.plist`.

После установки появятся стеклянная плашка и процент использования лимита
в строке меню macOS. Отправьте запрос в Codex: плашка раскроется, начнёт
показывать токены и анимацию огня. После завершения запроса она свернётся
до показателя использования лимита. Если данных о лимите ещё нет, увидите «—».

## Как пользоваться

- Нажмите на плашку, чтобы открыть аналитику по проектам, моделям и запросам.
- Перетащите плашку мышью в удобное место — положение сохраняется.
- Нажмите на процент в строке меню или правой кнопкой на плашку, чтобы открыть меню.
- Выберите «Завершить Codex Numbers» для выхода. При следующем входе в macOS
  программа запустится снова. Для ручного запуска откройте её в `~/Applications`.

Расход отражает локальные журналы Codex. Облачные задачи без локального журнала
не отображаются. Процент лимита обновляется по последним полученным данным Codex.

## Обновление

Откройте Терминал в сохранённой папке `codex-numbers` и выполните:

```sh
make update
```

Команда загрузит изменения из GitHub и переустановит приложение с перезапуском.
Если вы редактировали исходники, сначала сохраните свои изменения в Git:
обновление не перезаписывает локальные правки принудительно.

## Удаление

В папке проекта выполните:

```sh
make uninstall
```

Программа остановится; установленное приложение и автозапуск будут удалены.
Журналы и настройки самого Codex сохранятся. После этого папку исходников
можно удалить через Finder.

## Если что-то не работает

**Не находится `swiftc`, `make` или `python3`, либо компилятор не знает
`NSGlassEffectView`.** Установите или обновите Command Line Tools с SDK 26+.

**При установке появилось `Bootstrap failed: 5`.** Подождите несколько секунд
и повторите `make install`: предыдущий процесс мог ещё завершаться.

**Плашка не показывает расход.** Выполните локальный запрос в Codex. Затем
из папки проекта проверьте чтение журналов:

```sh
make snapshot
```

По умолчанию читается `~/.codex/sessions`. Если Codex использует другую папку,
задайте `CODEX_HOME` в окружении перед `make install`: установщик сохранит
этот путь для автозапуска. Никогда не указывайте путь к файлу авторизации.

**Нужны другие команды.** Выполните `make help`. Проверки подсчёта запускаются
через `make test`, локальные артефакты сборки удаляются через `make clean`.
