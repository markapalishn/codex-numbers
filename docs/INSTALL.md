# Установка Codex Numbers

Установка не требует исходников, API-ключа, Homebrew, Xcode или прав
администратора. Загрузите последнюю готовую версию со страницы
[GitHub Releases](https://github.com/markapalishn/codex-numbers/releases/latest).

## Что потребуется

- Mac с macOS 26 или новее для оформления Liquid Glass.
- Установленный Codex с локальными задачами: программа читает его журналы.
- Доступ к репозиторию GitHub, если он ещё приватный.

Релизная сборка универсальна и работает на Mac с Apple Silicon и Intel.

## 1. Скачайте актуальную версию

Откройте страницу
[последнего релиза](https://github.com/markapalishn/codex-numbers/releases/latest)
и скачайте файл `Codex-Numbers-X.Y.Z.dmg`. Номер `X.Y.Z` — номер текущей версии.

## 2. Установите программу

Дважды нажмите на скачанный `.dmg`, затем перетащите `Codex Numbers.app` в
папку «Программы» в открывшемся окне. После копирования откройте приложение из
«Программ». Оно сразу включит запуск при входе в macOS.

Если macOS спросит подтверждение для первой версии, откройте контекстное меню
приложения, выберите «Открыть» и подтвердите запуск. Это потребуется только
один раз, пока релиз не подписан сертификатом Apple Developer.

После установки появятся стеклянная плашка и процент использования лимита
в строке меню macOS. Отправьте запрос в Codex: плашка раскроется, начнёт
показывать токены и анимацию огня. После завершения запроса она свернётся
до показателя использования лимита. Если данных о лимите ещё нет, увидите «—».

## Как пользоваться

- Нажмите на плашку, чтобы открыть аналитику по проектам, моделям и запросам.
- Перетащите плашку мышью в удобное место — положение сохраняется.
- Нажмите на процент в строке меню или правой кнопкой на плашку, чтобы открыть меню.
- Выберите «Завершить Codex Numbers» для выхода. При следующем входе в macOS
  программа запустится снова. Для ручного запуска откройте её в «Программах».

Расход отражает локальные журналы Codex. Облачные задачи без локального журнала
не отображаются. Процент лимита обновляется по последним полученным данным Codex.

## Обновление

Откройте страницу последнего релиза, скачайте новый `.dmg` и тем же способом
перенесите приложение в «Программы», подтвердив замену. Запуск при входе и
настройки сохранятся.

## Удаление

В Finder откройте «Программы» и переместите `Codex Numbers.app` в корзину.
Чтобы отключить уже настроенный автозапуск, откройте Терминал и выполните:

```sh
launchctl bootout gui/$(id -u)/local.codex-numbers
rm ~/Library/LaunchAgents/local.codex-numbers.plist
```

Журналы и настройки Codex останутся на Mac.

## Если что-то не работает

**Плашка не показывает расход.** Выполните локальный запрос в Codex, затем
перезапустите приложение. Для диагностики из исходников можно выполнить:

```sh
make snapshot
```

По умолчанию читается `~/.codex/sessions`. Если Codex использует другую папку,
переустановите приложение из исходников с переменной `CODEX_HOME`; путь будет
сохранён для автозапуска. Никогда не указывайте путь к файлу авторизации.
